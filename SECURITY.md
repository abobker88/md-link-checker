# Security Policy

## Supported Versions

The latest published version on npm is supported with security fixes.

## Reporting a Vulnerability

If you find a security issue (for example, a way that a crafted Markdown
file or URL could cause `md-link-checker` to execute unintended commands or
access unintended files), please report it privately by opening a
[GitHub Security Advisory](../../security/advisories/new) rather than a
public issue.

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce it
- Any relevant Markdown input or command line used

We'll do our best to respond promptly and credit reporters in the release
notes, unless you'd prefer to remain anonymous.
